## 大阪府 `osaka.js` — 43自治体

- **データソース**: 大阪府 令和7年度市町村標準保険料率等の算定結果  
  https://www.pref.osaka.lg.jp/o100080/kokuho/iryouseido/hokenryouritsu/hokenryouritsu.html
- **全43市町村が完全統一保険料率**（令和6年度より府内統一）
- **医療分・後期分**: 3方式（所得割+均等割+平等割）
- **介護分**: 2方式（所得割+均等割のみ、平等割なし）
- **賦課限度額**: 医療65万/後期24万/介護17万（非標準。令和8年度より66/26万に引上予定）
- 資産割なし（全市町村）
- 料率: 医療9.30%/34,424円/33,574円、後期3.02%/11,034円/10,761円、介護2.56%/18,784円

## 宮崎県 `miyazaki.js` — 26自治体

- **データソース**: 宮崎県「保険税率の状況」（令和7年10月公表）、各市町村公式サイト
- **確認済み（実際値）**: 15市町（宮崎市・延岡市・小林市・日向市・西都市・えびの市・三股町・国富町・綾町・高鍋町・木城町・川南町・高千穂町・日之影町・五ヶ瀬町）
- **推計値（要確認）**: 11市町村（都城市・日南市・串間市・高原町・新富町・西米良村・都農町・門川町・諸塚村・椎葉村・美郷町）
  - 宮崎県集計の合算値から医療分60%・後期分22%・介護分18%で按分
- **資産割あり（4方式）**: 15市町村
  - 都農町: 資産割67.06%（県内最高水準）

- **綾町・椎葉村**: R7より資産割廃止

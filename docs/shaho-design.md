**作成日**: 2026-07-03
**ステータス**: Draft v1
**下調べ**: R8料率は一次ソース確認済み（協会けんぽ・厚労省・年金機構・健保連）

## 0. 基本方針

- **ドメイン**: shaho-keisan.jp（決定済。.com同時取得は検討中）
- **対象**: 協会けんぽ健保・厚生年金・雇用保険。組合健保（1,364組合）は網羅不可のため計算対象外とし、案内文で誘導
- **構成**: 47都道府県ページ＋全国トップ。給与額別の大量ページ生成はしない（ドアウェイ/薄コンテンツ回避）
- **差別化**: 任意継続 vs 国保の自治体別比較（kokuho-coreの1741自治体データと接続）
- 既存原則を踏襲: 制度ロジックはデータ化 / 年度分離 / slug不変 / 個人データ非保持 / 暗黙フォールバック禁止

## 1. データ構造（data/shaho/）

```
data/shaho/
  kenpo-2026.json        協会けんぽ47県料率＋介護＋支援金（年度ごと）
  koyo-2026.json         雇用保険 業種別料率（年度ごと）
  kosei-nenkin.json      厚年 固定料率＋上限スケジュール（年度分離しない※）
  standard-monthly.json  標準報酬月額等級表（改定時のみ更新）
```

※厚年は「年度」でなく**適用期間（validFrom/validTo, YYYY-MM）**で変わる（上限改定が9月）ため、年度ファイル分離ではなく期間スケジュール方式を採る。国保の年度分離原則の期間版。

### 適用期間の解決ルール（最重要）

すべての料率は**対象月（「○月分」）**で解決する。納付月ではない。

| 項目 | R8適用開始 | 落とし穴 |
|------|-----------|---------|
| 健保料率・介護1.62% | 2026-03分 | 任意継続は04分から |
| 子育て支援金0.23% | 2026-04分 | 健保と1ヶ月ずれる |
| 雇用保険 | 2026-04分 | 年度どおり |
| 厚年上限 | 2027-09に68万 | **年度途中に変わる** |

**engine.jsと同じ思想で、対象月に合致する期間データが無い場合は暗黙フォールバックせずthrowする。**（「表示はR8・計算はR7」型事故の防止）

## 2. 計算エンジン仕様（engines/shaho/）

純粋関数。入力→出力のみ、DOM/fetch非依存（js/core/kokuho.js と同型）。

```
calculateShaho(input, data) → result

input = {
  monthlySalary: number,   // 報酬月額（通勤手当込み）
  targetMonth: "2026-07",  // 対象月（必須・フォールバック禁止）
  prefSlug: "tokyo",
  age: number,             // 40〜64なら介護第2号
  koyoCategory: "ippan",   // 雇用保険業種
  bonus?: number           // 賞与（任意）
}
```

### 計算手順

1. **標準報酬月額の決定**: standard-monthly.json の explicitBoundaries（公式料額表から転記）で等級判定
   - 健保: 50等級（58,000〜1,390,000）
   - 厚年: 32等級（88,000〜上限は kosei-nenkin.json の capSchedule を targetMonth で解決）
   - ⚠️ 中点則による境界導出は**上位等級で公式表と不一致の疑い**（検証テストで検出済。50級下限: 中点則1,360,000 vs 公式1,355,000?）。必ず公式の報酬月額レンジを転記する
2. **健保** = 標準報酬月額 ×（県別率 ＋ 介護1.62%※40-64歳 ＋ 支援金0.23%）→ 労使折半
   - 率はいずれも targetMonth で期間解決（2026-03分は支援金なし、04分から加算）
3. **厚年** = 標準報酬月額（厚年等級）× 18.3% → 折半
4. **雇用** = **賃金総額**（標準報酬ではない）× 業種別の労働者負担率
5. **賞与**: 標準賞与額（1,000円未満切捨）× 各率
   - 厚年上限: 支給1回につき150万円 **[確認済 2026-07-03 年金機構]**
   - 健保上限: 年度累計573万円 [未確認・要検証]

### 端数処理 [未確認・要検証]

被保険者負担分を給与から控除する場合: 50銭以下切捨て・50銭超切上げ（事業主が現金払いする特約がある場合は別則）。実装前に協会けんぽ/年金機構のFAQで確定させ、テストケースを公式料額表の実額と突合すること。

## 4. サイト構成（生成対象）

```
shaho-keisan.jp/                計算ツール＋全国概況
shaho-keisan.jp/{pref}/         県別料率・計算・料額表（47ページ）
shaho-keisan.jp/{pref}/hyou.html 標準報酬×保険料の料額表
shaho-keisan.jp/hikaku/         任意継続 vs 国保 解説ハブ
```

- URLに年度を入れない（canonical蓄積）。PUBLISH_YEAR 相当は期間スケジュールで代替
- 任意継続の保険料 = min(退職時標準報酬月額, 300,000※要検証) × 県別率（全額自己負担）→ kokuho側の {pref}/{slug}/ 比較セクションから接続
- 構造化データ: FAQPage・BreadcrumbList。更新日と適用期間を明示。一次ソースへ発リンク

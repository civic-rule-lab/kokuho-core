# Civic Rule Lab 憲法

最終更新: 2026-05

---

## 核心思想

> **市民 ↔ 制度**

制度は市民のためにある。
しかし制度はしばしば難解で、市民に届かない。

Civic Rule Lab は、制度と市民の間の「翻訳者」であり「橋」である。

---

## ミッション

**日本の全自治体の制度情報を、誰でも理解・利用できる形で届ける。**

現在: 国民健康保険料の計算ツール
目標: 全国自治体 × 複数制度（国保・介護・保育・住民税・給付）

---

## 設計原則

### 1. 個人データ非保持

利用者の氏名・住所・個別所得は一切保存しない。
計算はすべてブラウザ上で完結する。
サーバーには制度データのみが存在する。

### 2. 制度への誠実さ

計算結果は「概算」であり「公式値」ではない。
この区別を常にユーザーに明示する。
過大な信頼を招く表現を用いない。

### 3. 市民目線の設計

制度の専門用語を平易な言葉で説明する。
「所得割率 7.71%」ではなく「前年所得に対してかかる割合」。
入力項目は最小限に（かんたん計算: 所得と人数のみ）。

### 4. 透明な情報源

使用している制度データの出典を明示する。
年度（令和7年度）と取得元を記載する。
不確かなデータは公開しない。

### 5. ユニバーサルアクセス

スマートフォンで操作できること。
高齢者・非技術者が使えること。
ネット環境が限定的な環境でも動作すること（静的サイト）。

---

## 禁止事項

- **個人情報の収集・保存**（氏名・住所・マイナンバー等）
- **計算結果の公式性を主張する表現**
- **古い・未確認のデータを公開すること**
- **広告による制度情報の歪曲**

## データ品質基準

| 基準 | 内容 |
|------|------|

## サービス構成

### ポータル

`kokuho-keisan.jp/`
- 都道府県・自治体選択
- 対応自治体の一覧表示

### 計算ページ（かんたん計算）

`/{pref}/{slug}/`
- 所得と世帯人数のみで概算
- 軽減判定（7割/5割/2割）を表示

### 計算ページ（所得ベース計算）

`/{pref}/{slug}/income.html`
- 未就学児・介護・給与年金人数を加味
- 資産割対応（該当自治体のみ入力欄表示）

### ロードマップ

| フェーズ | 内容 |
|---------|------|
| Phase 1（現行） | 国保計算ツール |
| Phase 2 | 全国47都道府県・全自治体へ拡張 |
| Phase 3 | 介護保険・保育料・住民税 追加 |
| Phase 4 | 制度横断（複数制度の合算・比較） |
| Phase 5 | 給付情報（受けられる支援の提示） |

## 技術方針

### 静的サイト

- すべてのページは静的HTML
- 計算ロジックはブラウザJavaScript
- サーバーサイド処理不要
- GitHub Pages / Cloudflare Pages でホスティング可能

### 自動生成

- 制度データ（JSON）を更新すれば計算ページが自動再生成される
- 手作業による全自治体ページの個別編集は行わない
- パイプライン: `data/ → engines/ → generated/ → {pref}/{slug}/`

### ロールバック可能な設計

- すべての変更は git で管理
- 年度ごとにデータを分離（`kokuho-2025.json` / `kokuho-2026.json`）
- 誤ったデータを公開した場合は即座にリバートできる

## 更新・運用ルール

1. 年度改定（毎年4月〜6月）は全自治体のデータを確認・更新する
2. データ更新前に `validate-kokuho-data.js` を必ず実行する
3. 主要自治体（各都道府県1〜2市）は公式計算例との照合テストを実施する
4. 更新後は `generate-official-pages.js` と `generate-selector.js` を実行する
5. git push 前に staging 環境で動作確認する
